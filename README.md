VELVET VAULT — a top-down stealth heist game. One thief, one museum, three floors of trouble: sneak past patrolling guards and their vision cones, dodge sweeping security cameras, grab the target haul of paintings, gems, idols and diamonds, then slip out the green EXIT door before the alarm hits 100%. Tools at a cost: smoke bombs to vanish through a cone, a fuse box to kill the cameras, shadow zones where the alarm climbs slower, and sneaking to move quietly.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — WASD/arrows to move, SHIFT to sneak, SPACE for a smoke bomb, ENTER to start, P to pause, M to mute.
